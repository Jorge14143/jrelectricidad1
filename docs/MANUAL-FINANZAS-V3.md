# Manual de finanzas — JR Electricidad V3

## Principio
Las finanzas representan ingresos y egresos del negocio de servicios eléctricos.

## Flujo de ingresos
Presupuesto aceptado → registro/facturación del servicio → pago del cliente → estado financiero.

## Registro
Consultar facturación de servicios, pagos, saldos pendientes, gastos, resumen por cliente y reportes.

## Indicadores
El sistema debe permitir conocer cuánto se facturó, cuánto se cobró, cuánto está pendiente, cuánto se gastó y el resultado del período.

## Materiales
Los materiales no son productos vendidos por JR Electricidad y no se incorporan como ventas, inventario ni facturación comercial.

## Buenas prácticas
Registrar pagos y gastos cuando ocurren y conservar backups periódicos.
