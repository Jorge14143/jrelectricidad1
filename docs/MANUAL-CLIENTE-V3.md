# Manual del cliente — JR Electricidad V3

## Registro e ingreso
El cliente puede registrarse e iniciar sesión para acceder a sus funciones disponibles.

## Perfil
Mantener nombre, email y datos de contacto actualizados cuando la interfaz lo permita.

## Presupuestos
El cliente puede consultar presupuestos disponibles y abrir el detalle.

## Aceptación o rechazo
Desde el enlace seguro del presupuesto puede revisar los servicios, total y condiciones y elegir aceptar o rechazar.

Cuando se solicita firma, el cliente puede completar sus datos y firmar electrónicamente dentro del flujo habilitado.

## Trabajos
Consultar los trabajos asociados y su estado.

## Turnos
Consultar o gestionar turnos según las funciones disponibles.

## Historial
Consultar el historial de presupuestos y trabajos asociados a la cuenta.

## Contacto
Para consultas puede utilizar los canales publicados por JR Electricidad.
