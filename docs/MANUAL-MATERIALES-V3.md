# Manual de materiales técnicos — JR Electricidad V3

## Propósito
La biblioteca de materiales sirve para preparar técnicamente los trabajos.

## Gestión
- Crear categorías.
- Crear unidades de medida.
- Crear materiales.
- Editar o eliminar registros.
- Asociar materiales a presupuestos/trabajos.
- Registrar cantidades necesarias.
- Consultar historial.
- Generar PDF técnico independiente.

## Regla comercial
Los materiales no tienen precio de venta dentro de este módulo y no forman parte del cálculo económico del presupuesto.

No utilizar este módulo para stock comercial, proveedores, compras, venta de productos, carrito, checkout, catálogo comercial o facturación de materiales.

## Ejemplo
Presupuesto #125:
- cable 2,5 mm² — 80 m
- cable 4 mm² — 30 m
- térmica 20 A — 2 unidades
- diferencial 40 A — 1 unidad

El resultado es una lista técnica/PDF independiente del total del servicio.
