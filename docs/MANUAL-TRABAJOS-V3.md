# Manual de trabajos — JR Electricidad V3

## Inicio
Un trabajo normalmente nace de un presupuesto aceptado.

## Gestión
- Consultar cliente y presupuesto.
- Definir estado.
- Planificar.
- Crear tareas/checklist.
- Registrar tiempo.
- Agregar notas y eventos.
- Asociar evidencias.
- Registrar materiales técnicos necesarios.

## Evidencias
Usar General, Antes, Después o Documento.

## Materiales
Registrar únicamente información técnica y cantidades. No convertir materiales en productos comerciales.

## Cierre
Antes de cerrar:
1. Completar tareas.
2. Registrar notas relevantes.
3. Adjuntar evidencias necesarias.
4. Verificar estado.
5. Confirmar información del cliente.
